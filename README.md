# GitHub Practice

My practice repository for learning GitHub, Python testing, and basic project management.

## Project Overview

This repository contains a simple calculator module and Python test cases. It demonstrates how to organize code, test functions, and manage project files using Git and GitHub.

## Files in This Repository

- `calculator.py` — Contains the calculator function.
- `test_program.py` — Runs the calculator with sample inputs.
- `test_cases.py` — Contains test cases to verify the calculator function.
- `.gitignore` — Excludes Python cache files from Git tracking.
- `notes.txt` — Contains GitHub practice notes.

## How to Run the Program

Make sure Python is installed on your computer.

Run the calculator program:

```bash
python test_program.py
```

Run the test cases:

```bash
python test_cases.py
```

## Git Commands Practised

- `git status` — Check repository status.
- `git add` — Stage files.
- `git commit` — Save changes in Git history.
- `git push` — Upload changes to GitHub.
- `git log --oneline` — View commit history.
